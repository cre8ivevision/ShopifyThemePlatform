# Shopify Theme Platform

Shopify Theme Platform is a long-term documentation and architecture repository for a modular, scalable, component-first Shopify theme framework.

## Purpose

This repository defines the product vision, technical architecture, design system, component strategy, development standards, roadmap, and future platform direction for the Shopify Theme Platform.

## Documentation

The documentation is organised under `docs/`:

- `00-foundation` - documentation standards, repository structure, terminology, and ADR process
- `01-product` - product vision, PRD, and product strategy
- `02-architecture` - technical and system architecture
- `03-design-system` - design language, skins, templates, and design tokens
- `04-components` - component architecture and component library specifications
- `05-theme-editor` - Shopify theme editor experience
- `06-companion-app` - companion Shopify app architecture
- `07-development` - engineering standards and implementation guides
- `08-testing` - QA, accessibility, browser, and performance testing
- `09-business` - business model, licensing, pricing, and support strategy
- `10-ai` - AI-assisted development rules and workflows
- `adr` - Architecture Decision Records
- `roadmap` - product roadmap and milestones

## Current Status

This repository is in planning and documentation bootstrap stage.
