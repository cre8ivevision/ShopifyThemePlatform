# Licensing Strategy

## 1. Purpose

This document defines the commercial licensing strategy for the Shopify Theme Platform. Licensing should protect premium value while remaining understandable and fair for merchants.

## 2. Licensing Principles

- Core functionality should remain reliable.
- Premium features should be clearly packaged.
- Licensing should support merchant growth stages.
- Agency and multi-store usage should be explicitly handled.
- Storefronts should fail gracefully if access changes.

## 3. License Types

| License | Purpose |
|---|---|
| Core Theme License | Access to the base Shopify theme |
| Premium Skin License | Access to advanced design systems |
| Template Pack License | Access to industry templates |
| App Subscription | Access to app-backed features |
| Agency License | Multi-client delivery model |
| Enterprise License | Advanced support and governance |

## 4. Entitlement Rules

Licenses should map to entitlements in the Companion App. Entitlements define which features, skins, templates, and services are available to each shop.

## 5. Expiry and Downgrade Behaviour

If access changes:

- Existing storefront should remain stable.
- Editing locked premium features may be restricted.
- Merchants should receive clear messaging.
- Support teams should see entitlement history.

## 6. Acceptance Criteria

- License categories are defined.
- Entitlement mapping is clear.
- Downgrade behaviour protects merchant trust.
- Agency and enterprise needs are considered.
