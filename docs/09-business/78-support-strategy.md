# Support Strategy

## 1. Purpose

This document defines support strategy for the Shopify Theme Platform. Support should be efficient, well-documented, and aligned with the platform's progressive complexity model.

## 2. Support Principles

- Prevent confusion through better onboarding.
- Document common workflows clearly.
- Separate theme support from custom development.
- Provide clear escalation paths.
- Use diagnostics where possible.

## 3. Support Categories

| Category | Examples |
|---|---|
| Setup | Installation, onboarding, theme configuration |
| Design | Skins, templates, visual settings |
| Features | Feature activation and dependencies |
| Performance | Loading, assets, diagnostics |
| App | Licensing, sync, dashboard issues |
| Customisation | Developer and agency-level changes |

## 4. Support Channels

Potential channels:

- Documentation
- Knowledge base
- Email support
- In-app help
- Video tutorials
- Agency support tier
- Enterprise support tier

## 5. Support Boundaries

Support should clearly distinguish:

- Product issues
- Shopify platform issues
- Third-party app conflicts
- Custom code issues
- Paid customisation requests

## 6. Acceptance Criteria

- Support categories are defined.
- Support boundaries are clear.
- Escalation paths can be developed later.
- Documentation and diagnostics are treated as support tools.
