# Marketing Components

## 1. Purpose

This document defines Marketing Components for the Shopify Theme Framework.

Marketing components help merchants communicate offers, build trust, promote campaigns, capture leads, and guide shoppers toward conversion.

---

## 2. Component Vision

Marketing components should be useful by default and flexible enough for campaigns, product launches, and premium storytelling.

```text
Promote clearly. Build trust. Drive action.
```

---

---

## 7. Accessibility Requirements

- Promotional text must remain readable.
- Countdown timers must not create inaccessible pressure patterns.
- Forms must include labels and error messages.
- Testimonials and reviews must preserve semantic text.

---

## 8. Performance Requirements

- Avoid heavy animation defaults.
- Load countdown scripts only when enabled.
- Lazy-load media and logo lists.
- Avoid third-party review scripts by default.

---

## 9. MVP Scope

First release should include Promo Banner, Image with Text, Testimonials, FAQ, Trust Badges, Newsletter Signup, and Logo List.
