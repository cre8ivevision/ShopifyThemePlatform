# Licensing

## 1. Purpose

This document defines licensing and entitlement requirements for the Shopify Theme Platform and Companion App. Licensing should protect premium value while keeping the merchant experience fair, clear, and trustworthy.

## 2. Licensing Principles

- Core theme functionality should remain stable and predictable.
- Premium capabilities should be clearly communicated.
- Locked features should be visible without being disruptive.
- Licensing should not break storefront rendering unexpectedly.
- Entitlements should be auditable and easy to support.

## 3. License Scope

Licensing may apply to:

- Premium skins
- Premium templates
- Advanced feature modules
- Analytics
- AI recommendations
- Multi-store usage
- Agency workflows
- Priority updates

## 4. Entitlement Model

| Entitlement | Purpose |
|---|---|
| Core | Included baseline access |
| Starter | Basic advanced features |
| Professional | Expanded skins, templates, and analytics |
| Agency | Multi-client workflows and reusable packs |
| Enterprise | Advanced governance and support |

Final commercial names may change later.

## 5. Storefront Behaviour

If a license expires or becomes invalid:

- Existing storefront should fail gracefully.
- Merchant should receive clear app dashboard messaging.
- Premium editing or new activation may be restricted.
- Critical live storefront content should not disappear abruptly.

## 6. Support Requirements

Support teams should be able to see:

- Current plan
- Active entitlements
- Feature access
- License history
- Recent entitlement changes

## 7. Acceptance Criteria

- Licensing protects premium features without harming trust.
- Entitlement categories are defined.
- Storefront failure behaviour is documented.
- Support visibility requirements are included.
