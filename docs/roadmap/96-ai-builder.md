# AI Builder

## 1. Purpose

This document defines the future AI Builder vision for the Shopify Theme Platform. The AI Builder should help merchants, designers, and agencies generate useful storefront configurations, layouts, content structures, and recommendations while preserving human control.

## 2. AI Builder Principles

- AI should assist, not take control away from the merchant.
- Generated outputs should use documented platform systems.
- AI should explain its recommendations.
- AI should avoid unsafe, inaccessible, or performance-heavy output.
- AI should support beginner confidence and expert speed.

## 3. AI Builder Capabilities

The AI Builder may support:

- Store setup suggestions
- Section layout generation
- Skin and template recommendations
- Product page improvements
- Landing page structures
- Content block suggestions
- Performance recommendations
- Accessibility suggestions

## 4. Inputs

AI Builder inputs may include:

- Merchant goals
- Store type
- Product catalog context
- Selected skin
- Active features
- Existing layout
- Analytics signals
- Performance signals

## 5. Output Rules

Generated output should:

- Use existing components and variants.
- Use approved design tokens.
- Respect accessibility rules.
- Avoid unsupported custom code.
- Provide preview and approval before publishing.

## 6. Acceptance Criteria

- AI Builder scope is defined.
- Human approval remains required.
- Outputs align with platform architecture.
- AI generation respects accessibility and performance.
