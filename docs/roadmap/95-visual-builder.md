# Visual Builder

## 1. Purpose

This document defines the long-term Visual Builder vision for the Shopify Theme Platform. The builder should provide a more guided and flexible experience while remaining Shopify-native and architecture-aligned.

## 2. Builder Principles

- The builder should not copy external platforms.
- It should use familiar mental models where helpful.
- It should remain compatible with Shopify theme architecture.
- It should use platform components, variants, blocks, and tokens.
- It should preserve performance and accessibility rules.

## 3. Builder Scope

The Visual Builder may support:

- Section layout editing
- Component variant selection
- Skin and template application
- Responsive previews
- Feature activation guidance
- Design token controls
- Preset management

## 4. User Modes

The builder should support:

- Beginner mode
- Designer mode
- Developer mode
- Agency mode

Each mode should expose the right level of control.

## 5. Architecture Relationship

The builder should consume existing platform systems:

- Layout Engine
- Component Registry
- Variant Engine
- Design Tokens
- Feature Manager
- Companion App APIs

## 6. Acceptance Criteria

- Visual Builder scope is defined.
- Builder remains Shopify-native.
- Builder uses existing platform architecture.
- Progressive disclosure is preserved.
