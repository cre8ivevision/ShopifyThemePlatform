# Design Patterns

## 1. Purpose

This document defines reusable design patterns for the Shopify Theme Platform. Design patterns help create consistent shopping experiences across components, templates, skins, and industry-specific implementations.

## 2. Scope

This document covers layout patterns, commerce patterns, content patterns, interaction patterns, trust patterns, conversion patterns, and responsive pattern behaviour.

## 3. Pattern Principles

- Patterns should solve recurring merchant and shopper needs.
- Patterns should be reusable across industries.
- Patterns should be configurable without becoming confusing.
- Patterns should support both minimal and premium design systems.
- Patterns should improve conversion without harming trust or usability.

## 4. Layout Patterns

Common layout patterns include:

- Hero with call-to-action
- Split content
- Feature grid
- Product showcase
- Collection grid
- Editorial story block
- Image with text
- Logo list
- Testimonial strip
- FAQ accordion

## 5. Commerce Patterns

Commerce patterns include:

- Product card
- Quick add
- Variant selector
- Price display
- Discount badge
- Product recommendations
- Cart drawer
- Trust messaging
- Shipping information
- Recently viewed products

## 6. Content Patterns

Content patterns include:

- Heading plus body plus action
- Media plus supporting copy
- Icon plus feature text
- Question and answer
- Step-by-step process
- Comparison table
- Before and after

## 7. Interaction Patterns

Interaction patterns include:

- Modal
- Drawer
- Accordion
- Tabs
- Carousel
- Filter panel
- Search overlay
- Sticky action bar

## 8. Conversion Patterns

Conversion-focused patterns should support:

- Clear primary action
- Trust building
- Social proof
- Product clarity
- Urgency without manipulation
- Reduced checkout friction

## 9. Skin and Template Relationship

Skins can change visual treatment, while templates can combine patterns into complete page experiences.

Example:

- A product showcase pattern may look minimal in the base skin.
- The same pattern may look editorial in a luxury skin.
- The same pattern may become dense and practical in a B2B skin.

## 10. Acceptance Criteria

- Patterns are documented independently from components.
- Patterns can be reused across templates.
- Patterns support minimal and advanced visual treatments.
- Commerce patterns prioritise shopper clarity.
- Interaction patterns include accessibility expectations.
