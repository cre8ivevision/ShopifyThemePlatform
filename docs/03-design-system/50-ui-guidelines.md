# UI Guidelines

## 1. Purpose

This document defines user interface guidelines for the Shopify Theme Platform. It translates the design system into practical rules for building consistent, usable, and scalable storefront interfaces.

## 2. Scope

This document covers component behaviour, controls, visual hierarchy, merchant-facing settings, storefront interaction, consistency, accessibility, and skin-aware UI decisions.

## 3. UI Principles

- Interfaces should be clear before they are expressive.
- The default UI should be minimal and easy to understand.
- Advanced visual quality should come through skins, templates, and presets.
- Components should behave consistently across the platform.
- Merchant settings should avoid unnecessary complexity.

## 4. Default UI Experience

The default UI should feel:

- Simple
- Clean
- Fast
- Neutral
- Familiar
- Easy to customise

This supports merchants who want a basic starting point without being overwhelmed.

## 5. Progressive UI Upgrade Path

The platform should allow merchants to move from basic to premium experiences through:

- Skins
- Templates
- Section presets
- Design tokens
- Feature Manager
- Advanced controls

The upgrade path should not require theme switching.

## 6. Controls and Actions

Common UI controls should be consistent:

- Primary button
- Secondary button
- Text link
- Icon button
- Input
- Select
- Checkbox
- Toggle
- Tabs
- Accordion
- Modal
- Drawer

## 7. Visual Hierarchy

Every interface should make clear:

- What is most important
- What action is primary
- What content is supporting
- What state the user is in
- What happens next

## 8. Commerce UI Guidelines

Commerce UI should prioritise:

- Product clarity
- Price readability
- Variant selection clarity
- Cart confidence
- Trust signals
- Fast path to purchase
- Clear error recovery

## 9. Theme Editor UX Relationship

Storefront UI and Theme Editor controls should align.

If a merchant changes a setting, the result should be predictable.

Beginner users should see simple controls. Advanced users should have deeper options only when needed.

## 10. Skin-Aware UI

Skins may change:

- Button style
- Card treatment
- Border radius
- Shadow depth
- Typography expression
- Spacing rhythm
- Motion feel

Skins should not change core usability rules.

## 11. Acceptance Criteria

- UI rules are consistent across components.
- Default interface remains minimal and usable.
- Skins upgrade visual quality without breaking behaviour.
- Commerce interactions remain clear.
- Merchant controls support progressive disclosure.
