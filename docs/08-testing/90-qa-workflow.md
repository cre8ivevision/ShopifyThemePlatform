# QA Workflow

## 1. Purpose

This document defines the standard QA workflow for the Shopify Theme Platform. The workflow ensures changes are reviewed, tested, classified, documented, and released in a controlled way.

## 2. Workflow Overview

```text
Change Request
  -> Scope Review
  -> Implementation Review
  -> QA Planning
  -> Test Execution
  -> Bug Classification
  -> Fix Verification
  -> Release Readiness
```

## 3. Scope Review

Before QA begins, identify:

- Changed files
- Affected components
- Affected skins or templates
- Affected merchant workflows
- Related documentation
- Regression risk

## 4. Test Execution

QA should run relevant checks for:

- Functional behaviour
- Visual consistency
- Accessibility
- Performance
- Browser compatibility
- Responsive layouts
- Documentation links

## 5. Bug Handling

When issues are found:

- Classify severity.
- Assign category.
- Document reproduction steps.
- Link related files and documents.
- Verify the fix after resolution.

## 6. Release Readiness

A change is release-ready when:

- Critical checks pass.
- Known issues are documented.
- Documentation is updated.
- Support notes are prepared if needed.
- Release checklist is complete.

## 7. Acceptance Criteria

- QA workflow is documented end to end.
- Bug classification is integrated.
- Release readiness is defined.
- Documentation checks are included.
