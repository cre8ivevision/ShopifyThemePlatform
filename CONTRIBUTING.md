# Contributing

This repository is currently in the planning and architecture stage.

## Documentation Guidelines

- Write documents in official English.
- Use Markdown for all documentation.
- Keep each document focused on one subject.
- Include purpose, scope, requirements, open questions, related documents, and revision history where relevant.
- Record major architecture choices as ADRs.

## Review Process

All major changes should be reviewed for consistency with the product vision, technical architecture, and documentation standards.
